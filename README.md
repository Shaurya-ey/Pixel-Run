<h1 align="center">Pixel-Run</h1>
<h4 align="center">A 2D, 2 microgame collection built with Godot 4. Play through back-to-back minigames : collect coins in a platformer, blast aliens in a space invaders.... and try to survive all rounds.</h4>

<hr>

How to play

- Arrow keys — Move
- Space / Up — Jump or Shoot (depends on the game)
- 5 lives — lose one each time you fail a round
