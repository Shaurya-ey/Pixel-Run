<h1 align="center">Pixel-Run</h1>
<h4 align="center">An 2D, 2 minigame collection built with Godot 4.7. Play through back-to-back minigames : collect coins in a platformer, blast aliens in a space invaders.... and try to survive all rounds.</h4>

## Why I made this project?
As an passionate Game enthusiast, I had an great interest to build my own Game from scratch on my own but due to lack of knowledge 5-6 years back i was unable to do that, but today as an undergrad student i made it possible!!

## How i made this Game?
I made this game with the help of the Stardance Guide as well as i have added many features from my side too. The software which i used to build this game from the very scratch is "GODOT-Game Engine" which has very user friendly interface which helped me a lot as a begginer.

## Features:

- This game has 2 different minigames which has to be completed in a time constraint of 10s to win
  1. Mario Run:
      - Has double press to double jump feature
      - Animated coins
      - Custom Platforms
  2. Space Invaders:
      - 12 Enemies
      - Enemies zig-zag + downward movement + time constraint makes this minigame more hard to clear
      - Space to shoot
- Auto-progression between games facilated by an 2s timer
- Can be played on Web on itch.io (HTML5 Format)
- Very lightweight/Total size - 2MB

## How does it work?
Try the game [here](https://shaurya-gen.itch.io/pixel-run)

## How to play

- Arrow keys (left and right keys) — Move
- Space / Up — Jump or Shoot 
- 5 lives — lose one each time you fail a round
